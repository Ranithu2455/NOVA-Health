## Implemented and Tested
- Registration (POST /api/Auth/register)
- Login (POST /api/Auth/login) — JWT token returned
- GET /api/Auth/me — returns authenticated user info
- GET /api/Profile — returns the authenticated user's profile
- PUT /api/Profile — updates the authenticated user's profile
- Persistence: EF Core + PostgreSQL mappings present; migrations exist

> Note: Other resource endpoints (medications, symptoms, etc.) are documented as planned since controllers are not implemented in the current snapshot.
